Operating Procedure

A repeatable sequence for obtaining traceable, usable data.

1. Plan the measurement

  1. Define the physical quantity, axes, locations, expected amplitudes, and highest frequency of interest.
  2. Select sensors whose calibrated ranges and bandwidths cover those values with margin.
  3. Select a sample rate greater than twice the highest frequency of interest and within the hardware/sensor limits. More margin makes anti-alias filtering easier.
  4. Estimate storage: samples per file = actual rate × block duration; total rows = samples per file × number of files.
  5. Choose a short block for responsive stopping and manageable files, or a longer block when analysis requires uninterrupted records. The GUI permits 1–3,600 s; the CLI uses 1 s.

2. Prepare hardware safely

  1. Make the DUT safe and secure the test fixture.
  2. Mount accelerometers rigidly in the documented orientation. Route and strain-relieve cables so they cannot pull on sensors or contact moving parts.
  3. Connect each sensor to the input recorded in the channel map.
  4. For every IEPE sensor, verify sensitivity and allowed excitation current from its calibration sheet/datasheet.
  5. For every position channel, determine the controller's voltage endpoints and corresponding positions. Calculate scale and offset before acquisition.
  6. Power and self-test the cDAQ system in NI MAX. Confirm the computer clock if correlation with other systems matters.

3. Configure the program

  1. Choose a local output directory and descriptive file prefix. Avoid reusing a folder ambiguously across unrelated tests.
  2. Enter the exact NI MAX module names.
  3. Set rate, block duration, sensitivity, IEPE current, format, and continuous/file count mode.
  4. Enter a unique Test ID and enough DUT/setup metadata to reconstruct the test later.
  5. On Channels, disable unused inputs and verify units, axes, locations, serials, bandwidths, and position scale/offset.
  6. Set display full scales near the expected peak values. These affect only meters, not acquired data or clipping limits.
  7. Review the Metadata Summary immediately before Start.

4. Preflight checklist

  • DUT and fixture approved for operation; emergency-stop procedure known.
  • Sensors firmly mounted; cables secure; channel map independently checked.
  • Sensitivity, IEPE current, position scale/offset, and units confirmed from source records.
  • Requested rate supports the analysis bandwidth.
  • Output path is writable, local disk preferred, and free space is adequate.
  • Test ID and changed setup details are current, not carried over from the previous run.
  • Only intended channels are enabled.

5. Acquire

  1. Press Start Acquisition. Do not begin the DUT sequence until state is Recording and the actual rate is shown.
  2. Observe at least one completed block at a safe baseline. Check for dead, implausible, or unexpectedly large channels.
  3. Run the test while monitoring the DUT independently. The GUI's red meter threshold is only a user-selected display threshold; it is not a hardware clipping detector or safety interlock.
  4. For a manual run, press Stop at the planned end and wait for Idle. For fixed count, wait for automatic completion.
  5. Do not disconnect hardware, close the application, or remove storage while a block is being read/written.

6. Verify before dismantling

  1. Confirm the expected file count and nonzero file sizes.
  2. Open at least the first and last file. Check Test ID, UTC time, actual sample rate, sample count, channel order, units, and sensor metadata.
  3. Plot or inspect each channel. Look for flat lines, discontinuities, clipping, unreasonable offsets, swapped axes, and position values outside the known range.
  4. Record anomalies in the test log. Do not silently edit acquired files; preserve originals and make corrected/derived data separately.
  5. Copy data to the project storage/backup location according to local procedure, then verify the copy before deleting any local data.

Position calibration example

If −10 V represents −5 mm and +10 V represents +5 mm:

scale = (5 - (-5)) / (10 - (-10)) = 0.5 mm/V
offset = -5 - (0.5 × -10) = 0 mm

Enter Units = mm, Scale = 0.5, Offset = 0. For arbitrary endpoints (V1, P1) and (V2, P2):

scale = (P2 - P1) / (V2 - V1)
offset = P1 - scale × V1
Sign matters: A controller whose voltage decreases as position increases needs a negative scale. Validate with two or more known positions.
