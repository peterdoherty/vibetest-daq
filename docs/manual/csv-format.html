Both contain the same sample values, channel order, time axis, and nonempty metadata. HDF5 size is predictable but is not compressed by this program. CSV size varies with numeric text.

Filenames and blocks

<prefix>_YYYYMMDD_HHMMSS_mmm.csv
<prefix>_YYYYMMDD_HHMMSS_mmm.h5

The timestamp is the calculated UTC start of the block, with milliseconds in the name. For example, vib_20260812_163015_123.csv. The file contents retain six fractional digits in the block-start timestamp/epoch. Each file contains one full block; the last file is not shortened to match a requested duration.

CSV structure

CSV begins with # comment lines, followed by a header row and numeric rows:

# NI cDAQ-9177 / NI 9234 + NI 9215 Vibration & Position Data
# Block start (UTC): 2026-08-12T16:30:15.123456+00:00
# Block start (epoch s): 1786552215.123456
# Sample rate (Hz):  5000.0
# Samples:           5000
# Channels:          2
# Sensitivity (mV/g):100.0
# Units:             g (acceleration)
# Test ID: FAN-SWEEP-001
# Channel Mod1_Ch0 Units: g
# Channel Mod1_Ch0 Sensor Type: accelerometer
# Channel Mod1_Ch0 Axis: X
# Channel Pos_Ch0 Units: mm
# Channel Pos_Ch0 Sensor Type: position
# ------------------------------------------------------------
time_epoch_s,Mod1_Ch0,Pos_Ch0
1786552215.123456,0.002341,1.25003
1786552215.123656,0.002417,1.25007

time_epoch_s is UTC POSIX time, printed to six decimal places. Channel values use up to eight significant digits. Acceleration values are in g; position values are already transformed by the configured scale/offset and are in each channel's declared units. The generic top-level Units line describes acceleration only; use each Channel ... Units entry for mixed data.

Read CSV with Python

import numpy as np

data = np.genfromtxt("vib_20260812_163015_123.csv",
                     delimiter=",", names=True, comments="#")
time_s = data["time_epoch_s"]
accel_x = data["Mod1_Ch0"]

For pandas, use pandas.read_csv(path, comment="#"). Spreadsheet software may round displayed epoch timestamps because they are large floating-point numbers; subtract the first timestamp in code to obtain precise relative time.

HDF5 structure

Root attributes

AttributeValue
block_start_utcISO 8601 UTC string
block_start_epoch_sUTC POSIX seconds
sample_rate_hzActual hardware rate
n_samples, n_channelsDataset dimensions
sensitivity_mv_per_gShared acceleration sensitivity
unitsg (generic acceleration attribute)
channel_labelsOrdered label array matching data columns

Nonempty system metadata is stored as root attributes using human-readable names such as Test ID, DUT Serial Number, and Test Notes. Per-channel attributes are also on the root and use the exact form Channel <label> <field>, for example Channel Pos_Ch0 Units or Channel Mod1_Ch0 Axis.

There are no attributes on the data dataset. Metadata readers must inspect the HDF5 root attributes, and names are case- and space-sensitive.

Datasets

DatasetShapeMeaning
time_epoch_s(n_samples,), float64Absolute UTC time for each row.
data(n_samples, n_channels), float64One enabled channel per column in channel_labels order.

Read HDF5 with Python

import h5py

with h5py.File("vib_20260812_163015_123.h5", "r") as f:
    fs = float(f.attrs["sample_rate_hz"])
    labels = [x.decode() if isinstance(x, bytes) else str(x)
              for x in f.attrs["channel_labels"]]
    time_s = f["time_epoch_s"][:]
    values = f["data"][:]
    test_id = f.attrs.get("Test ID", "")
    pos_units = f.attrs.get("Channel Pos_Ch0 Units", "")

Validate a dataset

  • Number of numeric rows equals Samples / n_samples.
  • Number of sensor columns equals Channels / n_channels.
  • Consecutive times differ by approximately 1 / sample_rate_hz.
  • Channel units, axes, locations, and serials agree with the test record.
  • First/last blocks have plausible start times and values.
  • No expected file is missing, zero bytes, or unreadable.

Storage estimate

Uncompressed HDF5 data payload is approximately 8 × samples × (channels + 1) bytes, plus a small header. At 5,000 Hz, five channels, and 10 s, that is about 2.4 MB per block. CSV will normally be larger and depends on the printed values. Measure a representative short run before planning long tests and keep generous free-space margin.
