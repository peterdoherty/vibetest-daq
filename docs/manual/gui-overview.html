Window organization

The Acquire tab controls a run and displays status. Metadata describes the test and DUT. Channels selects inputs and records sensor information/calibration. The bottom status bar reports connection, recording, stopping, and errors.

Start, stop, and close

Start Acquisition first saves all settings, rejects a run with no enabled channels, locks editable settings, creates the worker, and connects to the hardware. It does not perform semantic validation of metadata or calibration. Stop requests a stop; the current full block normally finishes before the task stops and queued output completes.

Closing during acquisition: Closing the window also requests a stop and waits approximately one block duration plus five seconds. Use Stop and wait for Idle whenever possible.

Peak meters

After each file is written, each active meter shows max(abs(channel samples)) for that block. Green is below 50% of the selected display full scale, amber is 50–80%, and red is above 80%. Disabled channels display off during acquisition.

Accel full scale (0.001–50 g) controls acceleration meters. Position full scale (0.001–1,000,000 in the channel's engineering units) controls position meters. These settings affect only display length/color; changing them cannot prevent or cause hardware clipping and does not rescale saved values. Position meter labels retain the channel's default um display label even if Units is edited, so use the numeric value and file metadata as authoritative.

Metadata Summary

The read-only summary shows Test ID, DUT, setup, up to six enabled channels with axis/location, and notes truncated to 120 characters. The full metadata is still written. Treat the summary as a final preflight prompt, not validation.

Settings persistence

Settings are saved when Start is pressed and when the window closes, using Qt QSettings under organization vibetest and application daq. They persist between runs and operators on the same user account. Always check stale Test ID, metadata, calibration, channel enable states, and output path.
