Acceleration setup

  1. Connect the X/Y/Z outputs to the mapped ai0/ai1/ai2 terminals.
  2. Enter the axes as actually mounted, not merely the sensor connector labels.
  3. Use one set of sensors compatible with the shared sensitivity and IEPE settings.
  4. Record individual serials and bandwidths. If calibrated sensitivities differ enough to matter, use separate runs or update the program to support per-channel sensitivity.

Position scale and offset

The NI 9215 reads voltage, and the program asks the DAQ driver to return scaled values:

value_in_units = scale × measured_volts + offset

Use two known calibration points and the equations on the Operating Procedure page. Then test an independent position. A default scale of 1 means 1 unit/V and is unlikely to be correct by accident. Zero scale forces a constant output equal to Offset.

Units are labels, not conversions. Changing Units from um to mm does not divide data by 1,000. Change Scale and Offset consistently.

Channel order

Enabled channels keep the fixed order shown above. CSV columns and HDF5 data columns follow that enabled subset. For example, if only Mod1_Ch1 and Pos_Ch0 are enabled, they appear in that order.

What is saved

Only enabled channels have samples and per-channel metadata written. Nonempty fields are stored using keys such as Channel Mod1_Ch0 Units, Sensor Type, Bandwidth (Hz), Axis, Location, and Sensor Serial. Scale and Offset affect acquired position values but are not themselves written as metadata, so document the calibration source in Notes or your test record.

Traceability limitation: Because scale and offset are not written to output files, preserve the GUI settings/calculation externally if raw-voltage reconstruction or calibration auditing may be required.
