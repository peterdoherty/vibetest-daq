Channel Layout

The hardware provides eight accelerometer input channels across two NI 9234 modules, plus two position-sensor input channels on an NI 9215:

Mod1_Ch0Module 1 (NI 9234)ai0AccelerometerX
Mod1_Ch1Module 1 (NI 9234)ai1AccelerometerY
Mod1_Ch2Module 1 (NI 9234)ai2AccelerometerZ
Mod1_Ch3Module 1 (NI 9234)ai3Accelerometer—
Mod2_Ch0Module 2 (NI 9234)ai0AccelerometerX
Mod2_Ch1Module 2 (NI 9234)ai1AccelerometerY
Mod2_Ch2Module 2 (NI 9234)ai2AccelerometerZ
Mod2_Ch3Module 2 (NI 9234)ai3Accelerometer—

The fourth channel on each NI 9234 module has no default axis assigned since the mounting arrangement (triaxial + spare, or four independent uniaxial sensors) depends on your test setup — set it on the Channels tab to match.

Accelerometer vs. position channels: which physical module and input each channel uses is fixed by the hardware wiring above and cannot be changed from the GUI. The Sensor type field described below is a free-text metadata label only (for CSV/HDF5 headers) — changing it does not change how a channel is configured on the DAQ.

The Channels Tab

The Channels tab shows a table with one row per channel. Each row has the following columns:

ColumnDescription
Enable A checkbox that includes or excludes this channel from the acquisition. When unchecked, the channel is not configured on the hardware, no data is recorded for it, and its level meter on the Acquire tab shows "off".
Channel The fixed hardware channel name (e.g., Mod1_Ch0). This is read-only.
Sensor type A free-text metadata label (e.g. accelerometer, position) written to the CSV/HDF5 header. Editing it does not change how the channel is wired on the hardware — that's fixed by which module the channel belongs to (see the Channel Layout table above).
Units The engineering units for this channel's values (e.g. g, mm, um). For position channels, this should match the units your Scale/Offset values are calibrated in.
Bandwidth Usable sensor bandwidth in Hz from the datasheet. Optional — leave blank if unspecified.
Axis The measurement axis label for this channel. Defaults to X, Y, or Z on the accelerometer channels. You can change this to match your sensor orientation or use any short label you prefer.
Location A free-text field describing where on the DUT this sensor is mounted. For example: Top plate, Base flange, Motor housing.
Sensor serial The serial number of the physical sensor connected to this channel. Useful for traceability when you need to know which sensor produced a particular measurement.
Scale (unit/V) Position (NI 9215) channels only. The slope of the linear conversion from raw volts to engineering units: value = scale × volts + offset. Disabled (grayed out) for accelerometer channels, which use the task-wide Sensitivity/IEPE excitation settings instead. For a Keyence LK-G5001, compute this from the analog output range and measurement range configured on the controller — it is not a fixed constant, so the default of 1.0 is only a placeholder.
Offset (unit) Position (NI 9215) channels only. The y-intercept of the linear conversion above: the engineering-unit value corresponding to 0 V. Disabled for accelerometer channels.

How Channel Metadata Appears in CSV Files

Per-channel metadata is written into the CSV header as comment lines. Only non-empty fields are included:

# Channel Mod1_Ch0 Axis: X
# Channel Mod1_Ch0 Location: Top plate
# Channel Mod1_Ch0 Sensor Serial: PCB-12345
# Channel Mod1_Ch1 Axis: Y
# Channel Mod1_Ch1 Location: Top plate
# Channel Mod1_Ch1 Sensor Serial: PCB-12346

Downstream analysis software can parse these headers to label plots as "Top plate X" instead of the generic "Mod1_Ch0". Position channels use the same mechanism — for example, # Channel Pos_Ch0 Units: mm and # Channel Pos_Ch0 Sensor Type: position.

Enabling and Disabling Channels

You do not always need all ten channels. If a test only uses three accelerometer sensors (one triaxial accelerometer, for example) and no position sensors, uncheck the unused channels. This has several benefits:

  • The CSV files are smaller because unused columns are omitted.
  • The NI-DAQmx task only configures the channels it needs, which can reduce bus bandwidth.
  • The level meters on the Acquire tab only show active channels, reducing visual clutter.
At least one channel must be enabled. If you try to start an acquisition with all channels disabled, the application will show a warning and refuse to start.

Persistence

Channel enable states, axis labels, location descriptions, and sensor serial numbers are all saved automatically. When you reopen the application, each channel is restored to its previous configuration.
