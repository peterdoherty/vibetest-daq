Vibetest DAQ Manual

Vibration and position data acquisition for the NI cDAQ-9177 chassis, using NI 9234 IEPE accelerometer modules and an NI 9215 analog voltage module. Developed at the Smithsonian Astrophysical Observatory.

What is Vibetest DAQ?

Vibetest DAQ is a data acquisition tool that records vibration measurements from IEPE (Integrated Electronics Piezo-Electric) accelerometers, together with position measurements from analog-output displacement sensors (such as Keyence LK-series laser sensors), connected to National Instruments hardware. It saves each block of samples as a timestamped CSV file that you can later analyze with spectral analysis software, MATLAB, Python, or any tool that reads plain text.

The package provides two ways to run an acquisition:

  • GUI (vibetest-daq-gui) — a desktop application with controls for all acquisition settings, test metadata, per-channel configuration, and live level meters.
  • Command line (vibetest-daq) — a headless script suitable for automated or unattended recording.

Each NI 9234 module has four input channels, so two modules give you eight accelerometer channels total (Mod1_Ch0–Ch3, Mod2_Ch0–Ch3). The NI 9215 provides two additional position channels (Pos_Ch0, Pos_Ch1) for Keyence sensor analog outputs — ten channels in all.

Note: The NI 9215 position channels do not use IEPE excitation or a mV/g sensitivity — each has its own linear scale (engineering units per volt, plus an offset) configured on the Channels tab. You must compute this scale from your Keyence controller's configured analog output range and measurement range; see Channels.

Key Concepts

IEPE Sensors

IEPE accelerometers contain a built-in charge amplifier powered by a constant-current excitation (typically 4 mA). The NI 9234 supplies this current and reads the resulting AC voltage. The sensitivity of the sensor (in mV/g) converts that voltage to acceleration in units of g (1 g = 9.81 m/s²).

Position Sensors

The NI 9215 has no IEPE excitation — it's a plain ±10 V analog input, used here for the analog voltage output of a Keyence laser displacement sensor. Unlike the accelerometer channels, each position channel has its own independent linear scale (value = scale × volts + offset) so it can report directly in the sensor's engineering units (mm, µm, etc.). That scale depends on how the Keyence controller's analog output range is configured relative to its measurement range, so it must be entered per channel rather than assumed.

Blocks and Files

Data is acquired continuously, but it is written to disk in fixed-length blocks. Each block becomes one CSV file. The block duration setting controls how many seconds of data go into each file. For example, at a 5 kHz sample rate with a 10-second block duration, each file contains 50,000 samples per channel.

Sample Rate

The sample rate determines how many readings per second the hardware takes on each channel. To capture vibrations up to a frequency f, you need a sample rate of at least 2f (the Nyquist criterion). A 5 kHz rate lets you analyze frequencies up to 2.5 kHz.

Note: The hardware may adjust the requested sample rate slightly to match its internal clock dividers. The actual rate used is reported in both the GUI status bar and the CSV file header.
